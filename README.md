🛒 Teto Shopping Website

A simple front-end shopping website inspired by the Teto aesthetic, built using **HTML, CSS, and JavaScript**.

📖 About the Project

This project was created as part of my front-end learning journey.

Rather than copying tutorials line by line, I used AI as a learning assistant to help me understand concepts, generate ideas, explain code, and solve problems while building the website. The goal was not to have AI build everything for me, but to learn how different front-end technologies work together in a real project.

Throughout the development process, I:
- Learned HTML structure and semantic elements.
- Practiced CSS layouts, styling, animations, and responsive design.
- Used JavaScript to add interactivity and dynamic behavior.
- Asked AI to explain unfamiliar concepts, debug issues, and suggest improvements.
- Modified, tested, and refined the generated code to better understand how it works.

This project represents my progress in learning front-end development rather than a production-ready e-commerce application.
